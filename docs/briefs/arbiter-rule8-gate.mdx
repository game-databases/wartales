extraction layer complete enough — all joins, derivations, and logic

consume contracts without deriving? Read the rule's authoritative

3. `EXTRACTION-LOG.md` — stage table (1–6 BUILT), frozen gates.

   relation, confirm a mechanism (hard/logic/inferred) exists in

  evidence layer with verified provenance; anything missing enumerated

  every open item visible in a ledger (no silent gaps). This gate must
  NOT pass on overclaimed PROOF language.

  RIDER (parallel, non-blocking, named owner piece) / P5-DoD-ITEM.
  Include explicit rulings on: R10b canonical wiring of `_logic`
  evidence into matrix.json/RELATIONS.md (blocks or parallel?); dig-14
  D-1 regex quirk; OCallClosure typing follow-up; unadjudicated
  name-hit adjudication queue; deferred UI-link surfaces.

Verdict at top, exactly one of:
- **GATE-OPEN** — frontend builds may start (Batch 3). List riders that
  MUST run in parallel with named pieces, and P5 items.

End with the axis table + rider list. Be exacting: this decision
