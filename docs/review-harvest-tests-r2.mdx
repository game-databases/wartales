## New-hole hunt (fixes only)

No tautologies among the new asserts — every message needle was verified
against a real implementation string (childCount :125, span :304,
`[media-hook]` :591, STOP AND REPORT :801, space gate :444, projection :462),
and the value-level asserts derive independently of the implementation. The
AV-magic negatives are the sharpest part: decoded bit-field by bit-field
against `_mpeg_audio_frame`, `ff fe 3c 00` (UTF‑16LE BOM XML) fails on
sample-rate-reserved and `ff e0 …` fails on layer-reserved — so either
negative fails the suite if anyone reintroduces the bare-sync branch. Fixture
soundness per spec §2 rides the round-1-audited writer unchanged; all new
fixtures tile honestly at KB cost.

Findings:

1. **N1 (recorded deviation, spec-owner item): tampered-source case narrowed.**
   Round 1 demanded exit 3 when re-running over intact targets after source
   corruption; that now completes rc 0 **by design** (§3.3 re-verifies TARGETS
   against stored hashes — corrupted source bytes never flow), and the test
   re-points detection at fresh-root extraction, documenting the behavior in
   its docstring. Internally coherent, and the post-fix resume shape was ruled
   correct under m7; but spec §7 case 8's letter ("adler mismatch detected on
   re-run of a previously-good extraction") now conflicts with what the suite
   pins. Needs a spec amendment (or an optional source-hash audit mode);
   optionally pin the rc-0 resume behavior explicitly so the design decision
   is mechanical, not docstring-only.
2. **N2 (accepted): case8 size_lies entry-naming widened** to accept the span
   reporter. Verified sound: with tiling + delta-0 enforced, entry-naming is
   provably unreachable under strict mode, the "span" needle is real
   (harvest.py:304), and the assertion still demands specificity. Within §7's
   intent for this flavor.
3. **N3 (cosmetic): stale comment "Σ = 197"** in the summary-contract test;
   actual Σ is 192 (128+64). Assert is correct; comment only.
4. **N4 (repo hygiene, pre-existing since r1 — route to orchestrator):
   `pipeline/tests/conftest.py` has never been committed.** The committed
   suite is not self-contained: without it the `integration` marker and
   `--run-integration` opt-in don't exist, so on a fresh clone the 3 smoke
   tests RUN instead of skipping and go red on any host without the client —
   48/0/3 is not reproducible from git alone. Not introduced by this fix
   round; needs one commit alongside the next suite touch (I commit nothing
   per brief).
