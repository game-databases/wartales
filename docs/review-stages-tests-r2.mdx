## 3. The RELATIONS.md tamper leg — redesign verified, two residual windows

The redesign does what the disclosure claims: backup lands FIRST in a
same-volume sibling; tamper and restore both go through fully-written
siblings + atomic `os.replace`; mtime restored; post-restore read-back
fails LOUDLY with regeneration instructions; fault clones exclude report
outputs so a crashed run cannot be masked by stale green reports
(:1239–1249).

Re-run twice per the brief: **pass in 5.62s and 6.05s**, `RELATIONS.md`
byte-identical after each, no debris siblings. The suite-scale run (which
executes the leg once more) and the integration run left the same hashes.
Steady-state behavior is safe.

Two residual windows found by reading the failure paths against this host's
disk pressure (C: at 100 %):

- **G1 (minor, ordered)** — if ENOSPC lands *during*
  `backup.write_bytes(original)` (:1378), the finally block replaces the
  still-intact shared file with the PARTIAL backup (`backup.exists()` is
  true for a partially-written file). The read-back then detects it, but
  the intact bytes are already gone pending manual regeneration — on the
  exact incident class the redesign exists to prevent. Hardening is two
  lines: publish the backup atomically (write `.tmp` sibling → `os.replace`
  to the backup name), or verify `len(backup.read_bytes()) ==
  len(original)` before proceeding to the tamper.
- **G3 (nit, ordered with G1)** — `finally` references `tampered` before
  assignment whenever a pre-tamper text op raises (marker absent, decode
  error, needle assert miss :1381–1389). The UnboundLocalError masks the
  true cause and — compounded with G1's scenario — would skip the loud
  read-back entirely (state restored or corrupted, but never explained).
  Init `tampered = None` and guard the unlink.

Irreducible and accepted: a hard process kill mid-leg leaves the tampered
MD plus the `.tw-backup` sibling as self-evident recovery evidence for the
seconds the validator runs — same class as the I3 snapshot/restore
precedent, and the general fakeroot lever stays deferred per the F15
ruling.
