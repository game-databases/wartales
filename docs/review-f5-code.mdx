## D. The two strict-xfail divergences

Both are encoded exactly right: `strict=True`, probe evidence quoted in
the reason, an XPASS-removal instruction, and companion positive tests
that hold the ACTUAL guarantee. Adjudicated on substance:

### XF-A — silent filter of non-searchable availability rows vs §9 item 5's "refused (exit 2)" letter → **ACCEPT-AS-XFAIL**

The letter cannot bind. §3.1's gate list ("Consistency gates (each a hard
exit 2)") is exhaustive and contains no such gate; §2's own growth law
expects avail to grow PAST the trio (34 kinds on disk today, wave-2 adds
more), so a blanket exit-2 on any non-searchable row would brick stage
`emit` on unrelated corpus growth and contradict §3.1's selection mandate
("Inputs read … Nothing else — the emitter selects, shapes, places").
What matters — artifact purity — is proven positively
(`test_non_searchable_kind_never_reaches_the_artifact`: exit 0, kinds and
rows ⊆ trio), and re-proven in this review's pytest run. **Errata
candidate:** reword §9 item 5's refusal clause to artifact-purity form
("a kind outside SEARCHABLE_KINDS never reaches the artifact"), and
consider the gate actually worth having: exit 2 when a NON-searchable
kind carries non-empty `namedLocales` — today a wave-2-ready kind ships
silently unsearchable, which is the true partial-wave risk §2 names.

### XF-B — stray overlay locale-dir blindness vs §3.1's union letter → **ACCEPT-AS-XFAIL**

Measured disk reality kills the naive enforcement: `extracted/locales/`
carries non-locale directories TODAY (`ui/`, `_draft-achievements/`), so
a literal directory sweep exits 2 on the production corpus. The emitter
reads overlays only through the nine-code lens (overlays dict keyed by
`LOCALES`), so a stray dir contributes zero bytes to any artifact; and
the plane that actually drives membership IS guarded — `ja` appearing in
avail's fields/namedLocales trips exit 2
(`test_unknown_locale_in_avail_refused_exit_2`, green). **Errata
candidate:** restate §3.1's locale-set gate over avail's locale
vocabulary plus the nine READ paths, with an explicit allowlist for tool
dirs; optionally warn on unknown *locale-shaped* dirs (`xx`,
`xx-YY`) so a future official-locale addition cannot pass silently.
