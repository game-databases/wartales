## 1. Attack A — no-carrier audit (761 rows)

Three independent probes, then a 19-row sample across 16 pairs. Result:
**zero missed carriers found on any row classed `no-carrier`.**

**A1 — hidden-sub-sheet schema census (V3).** The dig's residual sweep was
exact-name over draft strings; its schema check read only TOP-LEVEL metas
columns (`props` is type 17). So I enumerated every `6:<sheet>` reference
column declared inside data.cdb hidden sub-sheets

**A3 — 19-row sample across 16 pairs, per-row probes.** Rows: activity→skill,

## Findings

### MAJOR

- **M1 — 31 of 262 "unadjudicated-name-hits" directions are adjudicated by
  data.cdb itself; their ledger text asserts the opposite.**
  Anchor: `extracted/relinks/_logic/_ledger.jsonl` rows classed
  `unadjudicated-name-hits` vs `extracted/harvest/res/data.cdb` hidden
  sub-sheet columns. Examples: startChoice→counter
  (`startChoice@props.pathCounter = 6:counter`, 10/10 resolve), bonus→icon
  (`bonus@props.icon = 6:icon`, 43/43), trait→skill
  (`trait@props.skill = 6:skill`, 5/5), env→item
  (`env@camp.contextualTool = 6:item`, 18/18). Total: 31 directions /
  449 resolving refs (list in `output/_verify-dig15b/v3_schema_refs.json`).
  Every one carries the text "the matching paths carry **no schema type**
  (hidden sub-sheets … unadjudicable)" — false: the type IS declared in
  the hidden sub-sheets the same sentence proposes consulting, in a file
  the pack already harvests. Demonstrating probe: V3 census
  (`v3_schema_census.py`). Consequence: ≈12% of the class is derivable
  evidence misfiled as unadjudicable, and queue addition #2 ("adjudicate
  via hidden sub-sheet typing") asks for work already mechanically done.

- **M2 — the derived-family admission line is arbitrary, so the evidence
  layer is a subset, not a closure.** Same sheet, same proof strength,
  different outcomes: `startChoice.props.pattern→unitPattern` (typed
  6:unitPattern, 11/11) became flagship derived-evidence while
  `startChoice.props.pathCounter→counter` (typed 6:counter, 10/10) on the
  SAME sheet got parked as name-hits. Inside already-emitted families,
  additional typed carriers were left unemitted: `item__skill.jsonl`
  carries only `props.skill` (381) while `item@props.passiveSkill`
  (6:skill) resolves 283 more; `skill→status tooltipStatus[].st` resolves
  772; `class→status pitStatus/importantStatus/oils` resolve 34+7+7;
  `item.tool.tavern.bonuses[].bonus` 132. Modeled-direction fold notes
  were shipped for exactly ONE case (confessions→trait) while four equal
  cases went unfilled (counter→icon displayIcon ×8, status→attribute
  attributePercent/attributeValue ×8, item→itemType refCustomization ×8 +
  displayType ×1). Self-pair families were emitted for skill/bonus/mission
  but not item__item (`refItem` ×326, `refItemLoca` ×49,
  `converts.item` ×9), groupType__groupType (×57), fiefGoal/status/region/
  trait self-carriers — while the log presents the three as "the rest are
  self-chain families", implying exhaustiveness. Probe: V3 census + path
  tally of `_logic` evidence strings.

- **M3 — PROOF.md R10 closure phrasing overstates.** Anchor:
  `extracted/PROOF.md` R10: "DR bars 1–2 closed at evidence layer …
  Re-freeze only — no open extraction debt on bars 1–2." Given M1+M2 there
  IS open extraction debt on bar 1 (deriving ≥31 typed-carrier directions

  of M4. Bar 1's letter ("derived or concretely ledgered") is satisfied;
