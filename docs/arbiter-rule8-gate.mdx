## 1. Why the gate opens

Rule 8 asks whether every join, derivation, and logic reconstruction that is
possible from the extracted corpus is **finished or honestly ledgered** such
that frontend consumes contracts without deriving. Measured against that bar:

1. **The corpus itself is closed and proven.** 40,201 pak entries at Δ=0 byte
   accounting; CastleDB whole-file closure (11,473 rows reconciled by an
   independent verifier); HBSON decode 3,536/3,536 zero-slack + byte-exact
   re-encode; hlboot walked to EOF with slack 0 and decompiled twice over
   (operand + structured text, 52,114 functions / 2,508,050 ops, determinism
   proven by double emit); battle terrain 5,880/5,880 under a derived layout;
   world↔tile transform pinned by carrier arithmetic with a frozen-gate
   validation battery. Every "closed" row of PROOF.md traces to a counted
   artifact — the delta verifiers re-derived them independently and I found
   no surviving overclaim ([verify-dig15-delta §D7](verify-dig15-delta.mdx):
   `"no open extraction debt"` and `"no schema type"` both grep to zero).

2. **Relations are complete or concretely ledgered.** All 1,560 ordered
   directions are classified: 39 modeled hard, 89 derived-evidence
   (107 `_logic` family files / 7,184 edges / 0 dangling — sampler 107/107,
   full-corpus locator break attempt clean, independent delta recount exact),
   1,432 ledgered across nine classes with concrete unblocks. Nothing is
   silently dropped; the sweep limitation (exact-name matching) is recorded
   where it exists.

3. **Locale coverage is closed at GATE level.** 34 kinds × 9 locales, 88,441
   overlay entity rows, dual-extractor verified 217,611/217,611 with 0
   mismatch after the r2 fix round; drift reconciliation exact (14,456 =
   9,827 bridged + 4,629 absent-everywhere); filler census exhaustive and
   symmetric at exactly 3 instances; UI chrome layer emitted (en 2,148 /
   fr 1,897 addressable keys) with the fr vintage stamped `buildid-fallback`
   rather than invented. What remains is polish, not gaps (§4).

4. **Calculator-relevant logic is decoded and cited.** Capture odds
   (`battle.Unit.getCaptureChance` f#7774), prisoner roll (pcs 502–540),
   trade distance gradient (`st.Item.getLocalPriceFactor` f#6543, 50-unit
   free radius, pow gradient), combat XP composition (`Debrief.addXP`
   f#25108 + XpWin* constants), guard cap/pierce/backstab
   (`SkillTargetPreview.calcDamages` pcs 60–115), adaptive difficulty
   parameter sets ×18 levels ×21 region-tiers ×4 modes, terrain grid roles
   h/n/i/w — all exist as readable structured text with op ranges or hl-src
   line numbers a calculator can cite.

5. **The verification chain is real.** Six verdicts, three per dig, including
   two adversarial audits whose MAJOR findings were actually fixed rather
   than argued away (dig 14's silently-unemitted prose class; dig 15's misfiled
   typed carriers), then re-proven by delta passes. PROOF language was
   corrected downward where audits demanded it.

What keeps this from being unconditional: several data-answerable work items
remain possible from the corpus (deferred-kind outbound carriers, 126
unmapped UI windows, marker-layer typing, the trade-price static half,
protocol inventory). None feeds a Batch 3 surface, each has a named owner
piece, and each carries a batch deadline below — which is precisely the
RIDER class this gate exists to administer. A GATE-HOLD would idle foundations
that consume already-frozen contracts while adding no honesty; a pass without
deadlines would let later batches derive. This ruling takes the middle path
the rule's own routing vocabulary provides.
