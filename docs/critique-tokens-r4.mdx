## Verdict: WOWED

Say it plainly: this round closes the re-entry bar **5/5**, and for the
first time the preview survives the blind test completely — with the
captions covered and no legend, I would attribute the panel anatomy, the
type voice, and the rarity slots to Wartales' product family before
considering the palette, which is r1's original bar, met at last. The
bold axis is a true cut, proven below at the binary, the render, and the
preview's own pixels. No regression anywhere else: the r4 render is
pixel-identical to r3's except a single pixel (1600×1000 diff, threshold
24 — one stray pixel at (568, 675)), which is the cleanest possible
certificate that the only change this round is the binary, as mandated.

### The r4 bar — 5/5 PASS

| r3 bar condition | State |
|---|---|
| 700 byte-distinct from the 400 | ✓ `cmp` differs at byte 11; 25,340 B vs 44,336 B |
| 700 is a real bold cut, not a renamed 400 | ✓ fonttools: `usWeightClass=700`, `fsSelection` bold bit + `head.macStyle` bold set, name ID 4 = "EB Garamond Bold", **no `fvar`** — a true static instance of the variable original; cmap parity with the 400 (236 = 236 chars, 336 = 336 glyphs, zero missing) — a full instanced cut, not a trimmed subset |
| Bold renders from real 700 outlines (no synthesis) | ✓ A/B at 4× (`z-boldtest-4x.png`): the 700 line is a genuinely heavier design — thicker stems, tighter fit, different letterforms, advance 128 px vs the 400's 118 px at 22 px — not uniform smear; a synthesis control (`z-synthctl.png`, IM Fell 400 requested at 700) shows what real faux-bold looks like (ink 782 → 1226), and nothing on the page renders that way |
| All four r3 conditions hold, no regression | ✓ IM Fell identifiable in the 25 px display samples (spiky irregular serifs, crossed-stroke W, no ball terminals), EB Garamond in the 22/19/16/14 ramp, no Georgia in any stack or glyph; band, body, dialog and all three slot frames still render the extracted binaries; uncommon still nameable at arm's length; white hover outline still in the pixels (`c-hover` at 6×); 1-px total diff vs `preview-r3.png` |

One honest mechanism correction, on the record: r3 called the old defect
"Skia synthetic bold smeared over 400 glyphs." My controls show the truth
was one layer subtler — the 400 binary is a **variable** font, so
Chromium was instantiating true `wght=700` outlines from it all along;
the render never smeared. The defect was nonetheless real and
round-blocking at the contract layer: a file named `…-700-normal.woff2`
whose weight class was 400 is a false claim staged into what the site
ships — r2's mislabeled-specimen defect, one layer down, exactly as r3
ruled. What r4 fixes is the contract, and the 1-px render diff is the
proof that the pixels were already the true cut: the fix makes the file
tell the truth the render was already showing.

### Blind verdict (captions discounted, shots opened after)

- **Panel anatomy — pass.** Band + tucked body + double-hairline bevel +
  square corners; band titles centered; the 17-column grid fills its body
  edge to edge; label/value stat rows right-align their values. Against
  shots 02/03 after the reveal: centered band titles ("Inventory",
  "Trade", "Defence", "Attributes"), quiet framed wells, the same
  grammar throughout — same family, no tells left.
- **Type voice — pass.** Two voices, both true, both identifiable at 4×
  with no Georgia anywhere; the bold axis is real (above), so the
  tooltip's hierarchy — bold name, italic desc, bold values, gold price —
  now rides a cut the game itself has (`eb_garamond_bold.fnt`).
- **Rarity slots — pass.** Uncommon steel, rare olive + sheen, legendary
  violet + ring, common untinted and frameless: all four nameable at 1×
  without the legend, over the game's own `RarityBackground` tiles.

### §5 feel bar

- **Finished-object feel: pass.** The tooltip on real `dialogBg` chrome
  remains the best object this pack has produced; the inventory reads as
  holding objects, not demoing a grid.
- **Empty well honesty: pass.** One quiet same-size rectangle, no caption
  sentence about it.
- **Gold discipline: pass.** Currency gold on the price row and the one
  selected ring only; the `#FFFFAA` name is the game's rare-tip color,
  not gold creep.
- **Hover vocabulary: pass.** The white `outline(0.5, white)` state is
  rendered, bright and legible; captions label what is visible.
