### 2.4 Spacing, radius, borders

- **Spacing scale: 2 · 3 · 4 · 5 · 8 · 10 · 15 · 20** (5px base; `spacing:`
  5×125 + 10×104 dominate, `padding:` 5×92 + 10×92 — census rules per §6.4). Tokens `--space-1..8`
  in that order. Not a 4px grid — do not import Tailwind's default spacing
  rhythm uncritically.
- **Radius: 0.** Every game surface is square (9-slice corners are square).
  `--radius: 0rem`; rounded corners anywhere are a defect.
- **Border/bevel recipes** — the game builds chrome from 9-sliced textures
  (`background: url(...) X Y` = slice margins; (10,10) 76×, (20,20) 38×):
  - **Double border** (dialogs, popovers, tips): outer `#36322A` 1px, 1px
    gap, inner `#494339` 1px, fill `#0C0B09` (sampled from dialogBg.png,
    47×47, slice 20 20). Web: `border-image` from the extracted PNG, or the
    layered `box-shadow: 0 0 0 1px #36322A, 0 0 0 2px #0C0B09, 0 0 0 3px #494339`
    recipe — texture path preferred (shadcn-adoption: the game's panel, not
    a SaaS card).
  - **Section header band**: `HeaderBg.png` slice 10,10, height 35, title
    `#969696` EB Garamond 19, `offset-y -3` → web `translateY(-3px)`.
  - **Section body**: `SmallEntryBG.png` slice 10,10, padding 10,
    padding-bottom 15, `margin-top: -10` (body tucks under the header band —
    keep the overlap).
  - **Filter chips / small wells**: `dialogBg.png` slice 20,20, height 30.
  - **Button**: `buttonBg.png` **vgrid 3 frames** (normal/hover/pressed),
    slice 25 5, padding 5 25, height 30, label EB Garamond **bold** 16
    `#DDD8C5`.

### 2.5 Effects — the game's interaction vocabulary → web

| Game (domkit filter) | Recipe | Web translation |
|---|---|---|
| `outline(0.5, white)` ×38 | hover on buttons/chips/filters | `box-shadow: 0 0 0 1px rgb(255 255 255 / .5)`; text brightens to `#FFFFFF` |
| `glow(white, 0.5, 5, 2, 2, true)` | **selected** state (filters, tabs) | `box-shadow: 0 0 5px 2px rgb(255 255 255 / .5)` + white outline |
| `glow(#d8a519, 0.5, 40, …) outline(0.5, #d8a519)` | destiny-card highlight — the gold "featured" treatment | gold ring + 40px gold bloom (§3 top-tier border) |
| `glow(<player-color>, 1, 5, 1, 1, true)` | co-op identity glow | per-player token glow (§7 note) |
| `grayscale() + alpha .5 + text #888` | **disabled** (100 rules) | `filter: grayscale(1); opacity: .5; color: #888888` |
| `brightness(0.05/0.1/0.2)` | inactive/dimmed panels | `filter: brightness()` or dark overlay |
| `saturate(-0.4..-1)` | desaturated states | `filter: saturate()` |
| `text-shadow: 1 1 black` | all text over art | `text-shadow: 1px 1px 0 #000` |

Motion (foundation-guide §7): the game's states are texture-frame swaps
(vgrid) — near-instant. Web: 0.2–0.3s ease-out on outline/glow/opacity only;
`prefers-reduced-motion` honored; motion never gates content.

## 3. Rarity system (derived, not invented)

The game encodes quality in **two coordinated expressions** — both in
style.css:

**A. Slot frames** — `item-slot > #rarityBackground`:
`hgrid("ui/elements/RarityBackground.png", 3)`, 54×54 (107 for 2-wide/2-tall),
`visible: false` by default — **a common item shows no frame at all**.
Frames sampled from the extracted PNG (quilted-diamond alpha texture):

| Tile | Tier | Frame fill | Web token (wash) |
|---|---|---|---|
| 0 | uncommon | `#151A1E` steel-blue-black | `--rarity-1: #151A1E` |
| 1 | rare | `#272310` olive-gold-black | `--rarity-2: #272310` |
| 2 | legendary | `#251724` violet-black | `--rarity-3: #251724` |
| — | common | no frame | `--rarity-0: #BEBDBC` (untinted neutral) |

**B. Tip classes** — `item-tip.rarity_*`: name + background-tint pairs:

| Class | Name color | Tip bg tint | Web tokens (light) |
|---|---|---|---|
| `.rarity_u` | `#AAF` | `#BBF` | `--light-rarity-1: #AAAAFF`, `--rarity-1-wash: #BBBBFF` |
| `.rarity_r` | `#FFA` | `#FFB` | `--light-rarity-2: #FFFFAA`, `--rarity-2-wash: #FFFFBB` |
| `.rarity_legendary` | `#F8F` | `#FBF` | `--light-rarity-3: #FF88FF`, `--rarity-3-wash: #FFBBFF` |

Contrast of all three light tiers on `#1B150F`: 8.53 / 17.35 / 8.80 — AA ✓
(§6 matrix). `icon.qualitystar` (20–22px) marks quality beside tip names —
reuse the extracted icon, one icon vocabulary (design-standard §5.3).

This **reconciles and corrects** the INDEX screenshot reading: the
olive-gold wash (shot-03 helm) = *rare*, violet wash (shot-02) = *legendary*,
steel-blue wash = *uncommon*. The four hues INDEX listed also contain the
co-op **player-identity palette** — `#85C1E3`/`#D3B25E`/`#AFC073`/`#B5AADE`
are `player-1..4` (text+tint+outline+glow, 13 rules each), a separate system
that happens to share hues with the frames. Do **not** use player colors as
rarity tokens; keep both sets (`--player-1..4`) for co-op surfaces.

**Animated border, top tiers** (foundation-guide §7 pattern): legendary
gets the oversized-gradient-sheet border mask, `moveGradient` 5s alternate
infinite, gradient `#FF88FF → #B5AADE → #FFBBFF` over the `#251724` wash;
rare gets a static texture gradient (olive-gold); common/uncommon stay
quiet. Reduced-motion: gradient freezes to its first stop — tier stays
legible without motion.

## 5. Acceptance criteria

1. **Compiles.** `site/src/styles/tokens.css` builds clean in the site's
   Tailwind pipeline (CSS-variable theme per FRAMEWORK §2.20) — zero errors,
   zero unresolved `var()` fallbacks. Self-hosted faces land at
   `site/public/fonts/*.woff2` (§1).
2. **Every shadcn variable overridden.** The full stock variable set
   (`--background` … `sidebar-*`, `chart-*`, `--radius`, fonts) is defined
   in `:root` with §2.6 values; no stock default survives anywhere
   (component CSS included).
3. **≥90% value accounting.** A census script (`site/tests/census.mjs`,
   §6.1) counts every color and
   font literal in `style.css` (96 six-digit + 42 three-digit colors, 930
   occurrences; 5 faces, 14 sizes). Pass = ≥90% of occurrences mapped to a
   named token in this spec, and 100% either mapped or listed in the
   residue table §7 with its game context. No silent leftovers.
4. **Side-by-side critic pass.** Rendered components compared against
   `design/sources/` frames — minimum shot-02 (inventory/trade/dialogue),
   shot-03 (character panel), shot-07 (data rows), shot-17 (combat
   chrome) — graded against design-standard §5 and shadcn-adoption
   §Verification: must read as "the game's panel on the web", not "shadcn
   with a palette swap". A fail sends the builder back per adoption §Verification.

## 6. Test spec

1. **Token parity** (vitest over built CSS; token tests live under
   `site/tests/`): (a) no stock shadcn literals
   remain — assert against the shipped default set (`oklch(1 0 0)`,
   `0 0% 100%`, `--radius: 0.625rem`, default `--ring`, Tailwind palette
   classes in component files); (b) every shadcn variable name is defined;
   (c) rarity wash tokens equal the sampled frame fills
   `#151A1E/#272310/#251724` and light tiers equal `#AAAAFF/#FFFFAA/#FF88FF`
   — byte parity with `extracted-ui/` evidence; (d) `--radius` is 0.
   *Path note (F1 r1, orchestrator decision 2026-08-25):* the token tests
   ship at `site/src/styles/tokens.test.ts`, beside the file they parse —
   that path is authoritative over the `site/tests/` mention above.
2. **Contrast** (WCAG AA matrix): every `--text-*`, `--light-rarity-*`,
   `--positive`, `--negative`-text, `--warning` token × every `--bg-*`/`--card`
   surface it can ship on: ≥4.5:1 body sizes, ≥3:1 ≥19px bold / ≥25px (the game's
   own display sizes). Known constraint baked in: `#B63131` fails as text on
   dark (2.99:1) — the test asserts text-facing negative is `#E4696B`
   (5.63:1) and `#B63131` appears only as a fill under `#FFF7DB` (5.64:1).
3. **12px floor** (Playwright, design-standard §3): crawl every built
   template × canonical locale; assert `getComputedStyle().fontSize >= 12px`
   on every visible text node; assert no token below 12px exists (game's
   smallest, 14, is the floor-setter).
4. **Census script** (`site/tests/census.mjs`, criterion 5.3) ships beside
   the token tests and fails the
   build only when an unmapped **color or font literal** appears in style.css
   without a residue-table row — other style.css churn (spacing tweaks,
   selector moves, cosmetic patch noise) re-census without gating. Keeps the
   accounting honest across game patches (re-run on
   buildid change, spec automation `update-trigger: build-id`).
   **Census definition:** the script and every inline count in this spec
   share one rule set — word-boundary property matching (`text-shadow:`
   matches; `hspacing:`/`vspacing:` do not), selector-vs-value
   discrimination (filter functions such as `outline(0.5, white)` count as
   declaration values), and texture counting over the `ui/*.{png,dds}`
   reference pattern. Inline counts restated 2026-08-24 under these rules
   (§0 textures 225/860, §2.2 shadow ×28, §2.4 spacing/padding, §2.5
   outline ×38).

## 7. Residue ledger (documented, unmapped-at-token-level)

- **58 six-digit colors with ≤3 occurrences each** — combat reds
  (`#FF0000/#C50B0B/#8B0000/#F82121`), map legend states
  (`#68DE84` liberated-green, `#9E22A5/#AA00AA/#D04BD8` magenta markers,
  `#225DFF/#3589B9/#D1EAFF` blues), DLC-specific accents (black-market
  violet family). Each gets claimed by the component that owns its surface
  (combat overlay, map legend, market cards) at that component's build time;
  until then they live here, not in tokens.
- **Player identity palette** `--player-1..4` (`#85C1E3/#D3B25E/#AFC073/#B5AADE`)
  — tokenized, reserved for co-op identity surfaces only (§3 warning).
- **Font-size outliers** 15/17/18/20/21/23/28/35/60 — one-off display sizes
  (start-screen destiny cards, debrief headers, loading screens); map at
  component build time, never below the 12px floor.
- **domkit-only mechanisms** with no direct CSS equivalent —
  `color-adjust: gain()/saturate()`, `background-alpha: 1.2/1.5/2`
  (multipliers over 1), `hgrid/vgrid` state strips, `pad-*` gamepad props.
  The state-strip *semantics* (normal/hover/pressed frames) translate to
  §2.5 recipes; the properties themselves do not carry over.
- **`.asl` style libraries** — binary Photoshop presets; bevel/stroke
  recipes for icons are observable in the PNGs themselves; decoding is a
  separate dig if icon-recipe parity ever needs it.
